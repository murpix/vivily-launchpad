Quiero que generes una landing page profesional para mi app Vivily, totalmente personalizada y con diseño moderno. Esta landing debe incluir una sección de waitlist donde los usuarios puedan dejar su correo electrónico. El email debe guardarse automáticamente en mi base de datos de Supabase.
